# Aadhya Rao — Makeup Artist & Bridal Beauty Specialist

A bespoke portfolio and bridal beauty booking website for **Aadhya Rao**, bridal makeup artist and beauty specialist based in Bengaluru, India.

## Features

- **Editorial Visual Design**: Modern, warm aesthetic tailored for high-end bridal beauty and personal styling.
- **Interactive Portfolio**: Filterable gallery across Bridal, Engagement, Reception, Occasion, and Editorial concepts.
- **Detailed Look Modals**: Deep-dive into each curated styling concept with descriptions, skin-prep approaches, and key features.
- **Services Showcase**: Clear breakdown of bridal packages, pre-wedding rituals, occasion styling, and personal consultations.
- **Direct Enquiries**: Responsive booking enquiry form with direct WhatsApp business integration.
- **Performance & Accessibility**: Semantic HTML5 structure, responsive layout across all device sizes, and smooth micro-interactions.

## Tech Stack

- **HTML5 & CSS3**: Custom modern CSS design system with CSS custom properties and responsive grid/flexbox layouts.
- **JavaScript (ES Modules)**: Dynamic project filtering, modal viewer, form handling, and config-driven content.
- **Vite**: Ultra-fast local development and build tooling.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

Build the project for production deployment:

```bash
npm run build
```

The compiled output will be generated in the `dist/` directory.

### Preview Build

Preview the production build locally:

```bash
npm run preview
```
